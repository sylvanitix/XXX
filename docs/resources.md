## 📋 Guide d'Utilisation

### 1. Planification de Production

**Phase Prototype :**
- Utiliser massivement les assets **Kenney.nl** (gratuits)
- Compléter avec freebies de **CraftPix** et **Itch.io**
- Focus sur la mécanique avant l'esthétique

**Phase Production :**
- Investir dans packs premium de **CraftPix** pour cohérence
- Commander assets custom si nécessaire
- Peaufiner l'identité visuelle unique

---

### 2. Checklist Assets par Système

#### ✅ Système d'Invocation (Gacha)
- [ ] Animations de cristaux
- [ ] Effets de lumière/particules pour rarités
- [ ] Backgrounds cosmiques
- [ ] UI de résultat d'invocation
- [ ] Portraits de héros en haute résolution

#### ✅ Combat Idle
- [ ] Sprites de héros animés (idle, attaque, compétence, mort)
- [ ] Sprites d'ennemis (minimum 20 types)
- [ ] Effets de compétences (VFX)
- [ ] Arènes/backgrounds de combat (6+ environnements)
- [ ] UI de combat (barres HP, icônes cooldown)

#### ✅ Interface Utilisateur
- [ ] Menu principal (layout + boutons)
- [ ] Collection de héros (grilles, filtres)
- [ ] Shop (présentoirs d'offres)
- [ ] Progression (arbres de talents, prestige)
- [ ] Social (guildes, chat, classements)

#### ✅ Ressources et Économie
- [ ] Icônes de ressources (or, gemmes, essence, énergie, fragments)
- [ ] Équipements (armes, armures, accessoires) - 100+ icônes
- [ ] Particules de gain de ressources

## 💡 Conseils d'Optimisation Mobile

### Performance

**Textures :**
- Utiliser des atlas de sprites
- Compression adaptée (PNG-8 pour UI, PNG-24 pour héros)
- Mipmaps pour les textures 3D
- Limiter les résolutions (max 2048x2048 par atlas)

**Particules :**
- Limiter le nombre de particules simultanées (< 500)
- Utiliser des billboards pour les VFX 3D
- Pooling d'objets pour éviter l'instanciation

**Animations :**
- Sprite sheets plutôt que fichiers séparés
- Frame rate adaptatif (30 FPS pour idle, 60 FPS pour combat)
