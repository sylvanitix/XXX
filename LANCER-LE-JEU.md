## 🎮 COMMENT JOUER :

### 1️⃣ Démarrage
- Message de bienvenue apparaît
- Vous avez **500 💎 Gemmes** de départ
- **3 héros** vous rejoignent automatiquement

### 2️⃣ Combat
- Cliquez sur **"▶️ Auto"** pour lancer le combat automatique
- Tapez sur **"👆 TAP BOOST"** pour infliger des dégâts manuels
- Changez la vitesse avec **"⏩"** (x1, x2, x4)

### 3️⃣ Invocation
- Allez dans **"🎲 Invocation"**
- Invoquez des héros avec vos gemmes
- **Recommandé** : Cristal Majeur (300💎) pour 10% de Légendaire

### 4️⃣ Gestion
- **"👥 Héros"** : Voir votre collection avec leurs illustrations !
- Cliquez sur un héros pour voir ses stats et son design complet
- Améliorez-les avec de l'or

## 🚀 PROCHAINES ÉTAPES (OPTIONNEL) :

Si vous voulez **améliorer encore plus** :

1. **Remplacer les SVG par des images PNG/JPG réelles**
   - Suivez le guide `HOW-TO-ADD-GRAPHICS.md`
   - Trouvez des portraits de héros sur Freepik, ArtStation, etc.

2. **Ajouter des VFX animés**
   - Téléchargez des sprite sheets d'explosions, feu, etc.
   - Intégrez-les dans `combat.js`

3. **Personnaliser l'UI**
   - Téléchargez UI packs depuis Kenney.nl
   - Remplacez les boutons et cadres

**Mais honnêtement, la version actuelle est déjà très jolie ! 🎨**

## ❓ PROBLÈMES ?

### Le jeu ne se charge pas ?
- Vérifiez que JavaScript est activé
- Essayez un autre navigateur
- Appuyez sur F12 → Console pour voir les erreurs

### Les graphismes ne s'affichent pas ?
- Rafraîchissez la page (F5)
- Videz le cache (Ctrl + Shift + R)
- Le fichier fait 105KB, attendez qu'il charge complètement

### Je veux plus de héros graphiques ?
- Utilisez `dev.giveAllHeroes()` pour débloquer les 10
- Ou invoquez-les avec les gemmes
