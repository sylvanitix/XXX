# 🎮 LANCER ECLIPSE LEGENDS

## 🚀 MÉTHODE RAPIDE

### Étape 1 : Ouvrir le jeu
Ouvrez ce fichier dans votre navigateur :
```
game/index.html
```

**Ou** double-cliquez directement sur le fichier `game/index.html`

### Étape 2 : Jouer !
Le jeu se charge automatiquement. Vous verrez :
- Un message de bienvenue
- 500 💎 gemmes de départ
- 3 héros de départ

---

## 🎯 DÉMARRAGE RAPIDE

1. **Cliquez sur "▶️ Auto"** pour lancer le combat automatique
2. **Cliquez sur "👆 TAP BOOST"** pour infliger des dégâts bonus
3. **Allez dans "🎲 Invocation"** pour invoquer de nouveaux héros
4. **Gérez votre équipe** dans "👥 Héros"

---

## ⌨️ RACCOURCIS UTILES

- **ESPACE** : Activer/Désactiver auto-combat
- **T** : Tap Attack rapide
- **S** : Changer vitesse (x1, x2, x4)
- **1-5** : Changer d'écran

---

## 🎲 SYSTÈME GACHA

Vous avez **500 gemmes** au départ !

**Types d'invocation :**
- 💎 Cristal Mineur (100💎) : 70% Commun, 30% Rare
- 💎 Cristal Majeur (300💎) : 60% Rare, 30% Épique, **10% Légendaire**
- 💎 Cristal Sacré (500💎) : 50% Épique, **50% Légendaire**

**Astuce :** Invoquez x10 Cristaux Majeurs pour un Épique+ garanti !

---

## 🏆 HÉROS LÉGENDAIRES À OBTENIR

- ☀️ **Lyria** (Solari) : Meilleur healer du jeu
- 🌑 **Kael** (Umbrath) : DPS massif avec drain de vie
- 🔥 **Vorgrim** (Vorn) : Critiques dévastateurs
- 🌙 **Lunara** (Nivara) : Assassin ultra-rapide

---

## 💡 ASTUCES

1. **Améliorez vos héros** avec l'or pour augmenter leurs stats
2. **Équipe optimale** : 1 Tank, 2 DPS, 1 Healer, 1 Support
3. **Tap Boost** fait 30% du DPS total de votre équipe
4. **Le jeu continue hors ligne** jusqu'à 12h de récompenses
5. **Sauvegarde automatique** toutes les 30 secondes

---

## 🛠️ MODE TRICHE (Console)

Appuyez sur **F12** pour ouvrir la console, puis tapez :

```javascript
// 1 million d'or
dev.addGold(1000000);

// 10,000 gemmes
dev.addGems(10000);

// Obtenir TOUS les héros
dev.giveAllHeroes();

// Aller au stage 100
dev.skipToStage(100);
```

---

## ❓ PROBLÈMES ?

### Le jeu ne se charge pas ?
- Essayez un autre navigateur (Chrome, Firefox, Edge)
- Vérifiez que JavaScript est activé
- Ouvrez la console (F12) pour voir les erreurs

### Perdu ma sauvegarde ?
- La sauvegarde est dans le localStorage du navigateur
- Ne videz pas le cache pour conserver votre progression
